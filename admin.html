How this version works

GitHub-only catalog: products are not saved to an online database. This keeps the setup simple and free. You create the product entry here, download the updated products.js, then upload that file to your GitHub repository. Customers will then see the product on the live catalog.
  1. Upload the product photo to the images folder in your GitHub repository.
  2. Enter the same image path below, for example images/blender-1.jpg.
  3. Generate and download the updated products.js.
  4. Upload the downloaded products.js to the root of your GitHub repository and replace the old one.
  5. Wait a little for GitHub Pages to publish the update.
